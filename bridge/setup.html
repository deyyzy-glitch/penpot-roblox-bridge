Penpot Bridge is running

The helper connects Penpot and Roblox Studio on this computer. Keep it running for design transfers, even when your design needs no image uploads.

Required: local helper

Design transfer

Checking the local connection…

No Roblox upload key is required to connect, install the Penpot plugin, or send and receive a design. You can continue with the steps below and leave image setup closed.

  1. With this helper running, install http://127.0.0.1:43129/manifest.json in Penpot’s Plugin Manager and open Penpot to Roblox.
  2. In Penpot: Prepare selection → Send to Studio.
  3. In Studio: Receive from Penpot → Review import → Import design.

If Studio asks to contact 127.0.0.1, allow it: that address means your own PC. Start the helper again after a PC restart. Your finished game does not need it.

Optional: Roblox authorization

New image uploads

Checking upload setup…

An Assets Read/Write key is only needed when the helper must upload new image assets to Roblox. A design can transfer without it, but importing will need upload setup if it requires new images.

Some vectors, unsupported fonts, gradients, and effects are converted into images. Existing uploaded assets may be reused. A design made entirely of native UI needs no image-upload key.

Set up image uploads (optional)
The helper keeps a key entered here in memory and sends it only to Roblox for validation and uploads. Restarting the helper clears it. This does not stop key-free design transfers.

Troubleshooting

Penpot cannot install the plugin? Start the helper before clicking Install. Open helper status first, then install from http://127.0.0.1:43129/manifest.json. If the status page cannot open, the helper is not reachable.

After restarting your PC: run Start-Penpot-Bridge.cmd again. Extract the entire Windows ZIP and keep the helper window open while importing.

Nothing received in Studio? Prepare selection, then Send to Studio in Penpot. Next, Receive from Penpot in Studio. Preparing alone does not send the design.

Studio offline but helper status works? Check the connection in Studio. If you denied 127.0.0.1, review this plugin’s HTTP permission in Manage Plugins.

Images need setup? Configure your own Assets Read/Write key on the setup page. Restarting the helper clears the key. A key is not needed just to install the plugin.

Old interface or incompatible version? Update both the Studio plugin and helper. Close the old helper, run the new extracted copy, then reopen the Penpot companion.
