# Verification

`text-weight-fixture.mjs` and `studio-text-weights.luau` cover per-layer native weight choices. Seven checks run with the existing 2.7.4 importer: source default, editable ExtraBold, mixed RichText, verifier agreement, reset without instance replacement, protected Studio edits, and unchanged Image conversion. Node tests cover source immutability, token precedence, ignored image/covered overrides, validation, file scoping, saved choices, and mode/busy/reset behavior.

`studio-fractional-geometry.luau` takes Importer and the captured `machine-icon.json` fixture. Three live Studio checks compare every child’s absolute position and size to its authored fractional geometry, check padded image surfaces, and verify identity-preserving reimport and verifier agreement. Integer UDim offsets cannot represent these values directly; the importer stores the fractional remainder in scale. At the authored parent size coordinates are exact; when resizing, only that remainder (at most half a design pixel per component) scales with the parent.

`surface-render.html` is a browser regression for own-surface backgrounds. Serve it at `/` with the current `penpot/image-editor.js` at `/image-editor.js`, then click **Run render checks**. It compares every rendered pixel against a child-free gradient/stroke/rounded-clip reference, removes nested child graphics and external font declarations belonging to removed text, rejects unidentifiable surfaces, and retains dependency checks for intentional subtree exports and external images. Exporter tests separately prove that own-surface containers never accept an unchecked subtree PNG. These checks complement the Studio verifier, which inspects object state and cannot recognize duplicated lettering baked into image pixels.

`studio-gradients.luau` takes the built Importer, source Gradient module and verifier fixture. Eleven checks cover sample limits, authored stops, endpoint extension, transparency, source immutability, constant colors, native import integration, verification, idempotence and local edits. `studio-layer-controls.luau` takes Importer, the verifier fixture and horizontal grid fixture; its thirteen checks cover unresolved mappings, clone ownership/content, Layout mode, stable references, revision confirmation, retirement, skip/restore, metadata verification and grid templates. Run outside MCP undo recordings in a disposable sandbox.

`layer-modes.test.mjs` exercises export semantics and unsafe override rejection; `layer-editor.test.mjs` checks persistence, file scoping, stale selection responses, busy state and literal layer names. `build.test.mjs` verifies support modules survive packaging, including Luau dollar patterns.

`grid-fixture.mjs` and `studio-grids.luau` cover the opt-in native grid path. `verifier-fixture.mjs` and `studio-verifier.luau` exercise the read-only post-import verifier. Pass the fixture's document and Importer to the test function outside an MCP recording. Its 18 Studio checks cover clean imports, known font substitutions, old imported fonts, local edits and locks, missing/duplicate/wrong-class objects, parenting, empty and unresolved image references, expected versus new overlaps, user objects, unchanged instance state, duplicate wrappers, and visible versus hidden text overflow. The sandbox is removed after testing. A Studio UI-host smoke check additionally exercises loading the document, verifying the selected import, and rendering finding rows.
